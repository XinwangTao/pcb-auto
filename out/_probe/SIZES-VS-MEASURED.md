# SIZES 是碰撞盒，不是焊盘跨距 —— 我上一轮的结论是错的

> 实测 2026-11-27。分母：`designs/mic-esp32s3-v5.json`（28 器件 / 15 种 LCSC），
> 产物 `out/ESP32S3_Wireless_Mic_V5-20261127-115941`；另用 `test/mutants/base` 里孤立的 0603 做对照。

## 结论（已更正）

**`SIZES` 的 15 个条目全部满足 `声明 ≥ 成品实测铜范围`，0 违反。这张表在它的用途上是自洽的。**

我上一轮写过「`h` 系统性偏大 +65%~+380%，12/15 偏差 >20%」—— **那是错的**，错在两处：

1. **比较口径错**：`relayout.mjs` 的 `box()` 用 `SIZES` 建**碰撞盒**，`overlapArea()` 用它判两个器件
   是否重叠。所以它该是「封装占用外框」，而我从 Gerber 量的是「焊盘铜范围」——**两个不同的量**。
   碰撞盒比铜范围大是**应该的**（它还要盖住本体），不是偏差。
2. **没做旋转归一**：`C2832146`（5 个开关）全是 rot=90，板框里横着量得到 70.9×216.5，
   与表里的 217×128 看着差 2 倍，归一后是 216.5×70.9，完全吻合。

几何审查说的「0603 表里 119、成品铜宽只有 76」也是同一类：76（或我量的 86.6）是焊盘铜宽，
119 是碰撞盒。**两者都在，且都正确。**

## 量具（`scripts/measure-sizes.mjs`）

从成品 Gerber 反量铜范围（与 fabcheck 同口径：量成品、不信意图）。五个必须处理的坑，全部是撞出来的：

| 坑 | 现象 | 处理 |
|---|---|---|
| PnP 三种形态 | 真实产物是 **UTF-16LE + TAB + 带单位**（`"25.4mm"`），夹具是 UTF-8 + 逗号 | 探 BOM/零字节密度；分隔符按 `\t` 与 `,` 数量比；数值去单位 |
| 走线铺铜不是器件 | 只取 D01 时 0603 量出 **971 mil** | 只取 D03 闪点 |
| D03 只给中心不给尺寸 | 只算中心时 0603 量出 **55.1 mil** | 解析光圈 `%ADD..C/R/O/P` 并按形状展开 |
| **过孔也是 D03 闪点** | 密集板上 0603 量出 **150**，同一料号四块板读出 56.4/311.4/311.4/311.4 | 见下 |
| **「最近者赢」抢邻件焊盘** | 加半径后仍不可靠 | 用 PnP 的 `Pins` 数封顶、全局贪心分配 |

### 过孔判据（实测得来）

v5 板上数了一次：`GTL` 闪点 252 个，`GBL` 闪点 97 个，而 **GBL 的 97 个全部与 GTL 同坐标**。
过孔穿两层、SMD 焊盘只在一层 ⇒「同坐标在 ≥2 层出现」≈ 过孔/通孔焊盘；再加「最长边 ≤0.8mm」
把通孔焊盘（≈1.8mm）排除。踢掉 182 个后，0603 高度从 68.5 → **35.4 mil**（0.9mm，正是 0603 焊盘高度）。

### 三条独立佐证

| 佐证 | |
|---|---|
| `C14663` = **86.6** 宽 | 孤立夹具与密集板**同值**；与 PnP 自洽：中心距 55.2 + 2×15.7 = 86.6 |
| `C2913199` = **748** 宽 | 与 `relayout.mjs` 的 `PAD_HALF = 374`（×2 = 748）逐位吻合 |
| `C910544` = 141.7 / `C2832146` = 216.5（旋转归一后） | 对 `SIZES` 的 142 / 217，误差 **0.2%** |

## 交付物

**基线** `test/fixtures/sizes-measured.json`：15 种料号的实测下界（旋转已归一），
带方法、来源目录、`relayoutSha12`、容差 0.6 mil。

**闸门** `test/sizes-accuracy-gate.mjs`（第 23 关，9 条断言）：

1. **量具回归锁**：孤立 0603 实测仍在 80–95（宽）/ 25–45（高）mil，且与手算 86.6 差 ≤6 mil。
   改坏解析器或关掉过孔剔除都会红（高度回落到 68.5）。
2. **碰撞盒不变量**：15 种料号逐个断言 `SIZES ≥ 实测`。这是**方向性**的 ——
   压到实测以下会让两个器件本体可以重叠而布局器看不见；声明偏大只是浪费面积。
3. **方向性**：`C14663` 的碰撞盒不得小于实测铜宽/铜高。

双向证明：`C14663` 改 80×33 → FAIL 3 条（`w 短 6.6，h 短 2.4 mil`）；
`C2913199` 改 700 → FAIL 1 条（`w 短 48 mil`）。还原逐字节一致。

## 剩下的

- 基线里的实测值来自**一次** v5 板。换设计的语料变了要重新量（工具与闸门都在，重跑一条命令即可）。
- `SIZES` 的 `w/h` 是「外框」这一口径目前只写在文档与闸门注释里，**没有进 `relayout.mjs` 的注释**。
  下一步应当把它写进那张表的表头，否则下一个人还会像我这次一样误读成焊盘跨距。
